# Changelog

## 0.1.0 — 2026-10-12

- Created a private local PDF workspace with a new three-pane frame.
- Added SQLite document indexing, FTS5 search, editable classification rules, tags, pins, deduplication and version restore.
- Added persisted local pipelines, watched-folder imports, run history, progress and notifications.
- Reused the free PDF tool panels, viewer and editor.
- Added appearance preferences, local processing settings, optional passcode lock and local signing-identity generation.
- Removed excluded application modules, telemetry implementations and update requests; bundled branding, fonts and dependency notices.

See `docs/VERIFICATION.md` for tested behavior and remaining limitations.
