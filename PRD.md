# TearPDF

Private, offline PDF workspace for one local user. The primary interface uses the audited free frontend's original layout and workflows, with TearPDF branding. This supersedes the initial custom three-pane design request.
Reuse the audited MIT-covered upstream tools and frontend stack. Add SQLite library indexing and full-text search, document versions, watched folders, classification, pipelines, notifications, settings, and local demo documents.
Preserve the original reader, editor, file manager, tool panels, search, preferences and responsive behavior. Keep the added SQLite library and automation workspace available at /local-workspace from the navigation rail. Dark and light themes use the existing design system, bundled Inter, and TearPDF assets.
No telemetry, CDN dependencies, update pings, or runtime outbound requests. Timestamping remains off unless explicitly configured.
Publish a new private repository only after license approval, implementation, validation, and repository-name availability checks.
